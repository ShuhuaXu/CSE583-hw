# Homework 1 – Bicycle Data Analysis

## Process

1. Loaded the bicycle data from a CSV file and checked the data types.
2. Converted the columns to appropriate data types and added total count, hour, and year columns.
3. Filtered the data for 2016 and removed rows with missing values.
4. Plotted the total bicycle counts by hour and saved the figure.
5. Calculated the average bicycle count for each hour to identify the busiest hour.

## Results

- Missing data: 1 row
- Busiest hour: 5 PM (17:00)
